# React Portfolio

A modern, responsive portfolio website showcasing my projects and skills as a web developer.

## Features

- **Portfolio Showcase**: Display of featured projects including JustShare, ParkPay, JustStream, and JustChat
- **About Me Section**: Personal information and background
- **Contact Form**: Easy way for visitors to get in touch
- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Accessibility**: Built with WCAG guidelines in mind, including skip links, semantic HTML, and ARIA attributes

## Projects Featured

- **JustShare** - File Sharing Platform (Web Development)
- **ParkPay** - Parking Payment App (UI/UX Design)
- **JustStream** - Streaming Dashboard WebApp (Frontend Development)
- **JustChat** - Chat Application (Creative Design)

## Technologies

- React 18.3.1
- React Scripts 5.0.1
- CSS3 with modern styling
- Semantic HTML5

## Getting Started

Navigate to the `my-react-app` directory and follow the instructions in that README.
